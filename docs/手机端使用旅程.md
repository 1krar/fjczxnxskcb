# 手机端使用旅程

| 场景 | 用户要做的事 | 页面路径 | 完成反馈 |
| --- | --- | --- | --- |
| 早起、午休后回教室 | 确认这一趟带什么书 | 今日 → 带书清单 → 查看优先展开的时段 | 每门课显示已记录的教材，没填的课程可以直接记 |
| 安排一周 | 横向比较七天的安排 | 课表 → 整周 → 点课程长条 | 确认日期、节次和课程详情，想看当天细节时切到单日 |
| 晚上有活动 | 记录销假 | 点晚自习 → 选原因，或添加自定义标签 | 课表当晚显示销假和原因，新增标签下次可选 |
| 今天或明天出门前 | 按天气选一套 | 穿搭 → 选日期 → 查看首选 → 选这套 | 显示已选计划，备选和评分依据按需展开 |
| 搭出一套常穿的衣服 | 保存组合、补季节 | 常用搭配 → 连接一套搭配；也可给已有搭配编辑季节 | 保存后参与对应季节推荐，可穿状态与冷暖适配优先 |
| 穿完或要洗衣 | 记实穿、更新衣物 | 实穿记录；或衣物洗晒 | 查看已选与实穿，确认单件和整套洗晒状态 |
