# UI 改版实施与验收

日期：2026-10-24。设计基线：`e2516a4`；前端缓存版本：`20261024-1`。

依据：[全面自检与改版方向](UI-UX全面自检与改版方向-2026-10-24.md)。本轮完成主要路径与页面层级调整，并为实际 DOM 排序增加局部过渡。

## 已实施

### 课程与首页

- 手机和桌面课表均支持周一到周日。周末进入时选中今天；无课日明确标出日期，并提供下一周入口。窄屏会把选中的日期滚入可见范围。
- 已结束课程保持正常文字透明度，改用灰色边线、背景和“已结束”表达状态；课程名称可用键盘打开详情。
- 桌面课名加大至14px，教室和教师保持12px；小节与课间明细继续保留。
- 手机本周统计默认折叠，先显示所选日的课程。
- 无课日首页以“今天无课”为主，下一有课日以简短预告显示。
- 底栏文字从10px改为12px，未选中颜色使用次级正文色。浅色下该色为 `#475569`。

### 衣橱

- 首次进入直接录衣物，隐藏依赖衣物的推荐、批量洗晒和空统计。首次添加成功后，定位到推荐区域。
- 有衣物后依次展示穿搭准备、实穿记录、衣物与常用搭配。删除手机端跨模块 `grid-row` 重排，视觉顺序与 DOM 一致。
- 天气和活动摘要收紧；推荐单品突出显示，备选按需展开，推荐依据与 AI 偏好收进辅助详情。
- 校园跑开关即时保存并反馈。
- 衣物行保留名称、状态和近期穿着次数；完整统计、洗晒状态、编辑和收起放入详情。选中后才出现批量操作。
- 实穿行保留记录／评分主操作，撤销、恢复、取消计划和收起放在“更多操作”。保留原有实穿计数、洗晒独立、计划与实际分离的语义。
- 推荐刷新保留 AI 想法和展开状态；衣物刷新保留展开的详情；记录更新尽量把焦点返回原行。
- 全部衣物收起后，恢复入口及已有实穿历史仍可访问。
- 成功反馈在屏幕底部短暂出现，主要错误保留显示。

### 事项、数据与设置

- 空事项页隐藏零计数筛选和搜索，保留一个记录主入口；已有记录时仍可筛选、搜索、查看历史与回收站。
- 数据页先显示当前数据来源、导入和变更预览。学期、班级与文件检查折叠；“文件结构检查”明确不代表已核实临时调课。
- “更多”改为日常准备、课程与提醒、设置与数据三组行列表，避免长标题在三列小块中碎裂。
- 设置、AI、提醒、数据、事项和日程页隐藏重复的悬浮“记一下”，避免覆盖表单。
- AI 调用说明、授权检查／退出，以及大 A 的完整设置按需展开。保存结果与错误集中在保存栏；模型、授权期限、限额及服务端密钥逻辑未改动。
- 手机日历初始为周视图，月历可展开。跟随今天时跨日更新；主动选定历史日期时保留选择，点击“回到今天”恢复跟随。

### 局部动效

- 首页模块移动、长按排序让位使用已有 DOM 节点的约180ms位移过渡。
- 顺序先在 DOM 中真实更新；保留键盘排序、取消、焦点和持久化。
- JavaScript 在减少动态效果偏好开启时跳过新增位移；没有新增动效库。

## 后续仍需实测

- 真实手机的软键盘、触摸长按拖动、系统放大文字与低性能表现。
- 实际深色和系统减少动态效果模式。本轮核查了语义色及代码分支，未冒充设备实测。
- 跨午夜时，正在填写的长表单／弹窗是否被应用级整页刷新打断，需要单独验证和处理。
- 新增动画只覆盖稳定节点的移动；完成／撤销等会重建列表的操作，尚未加入退出动画。

本轮调整解决当前主要可读性、入口顺序和视觉层级问题；后续按真实使用反馈继续精修。
