# 第一批实施记录：设备授权与每日一句

日期：2026-10-23（北京时间）。

## 已实现

### 设备授权

- API设置新增“解锁时记住这个设备（30天）”，默认不勾选；保持6位数字或原有长口令。
- 勾选后签发30天随机授权；不勾选时使用浏览器会话Cookie，服务端最长8小时。浏览器的会话恢复可能保留会话Cookie，8小时期限始终由服务端检查。
- 浏览器仅保存随机Cookie，附带 `Secure`、`HttpOnly`、`SameSite=Strict`、`Path=/`，无Domain属性；原始口令不再写入localStorage或sessionStorage。
- 现有AI_DB自动建立ai_sessions表，只存凭据哈希、所有者摘要、创建／到期／最近使用时间和是否记住；不需要新增密钥或绑定。
- 免费状态接口恢复授权；提供退出当前设备、退出全部设备。更换服务端口令或百炼密钥会使原授权失效。
- 新旧鉴权在发布过渡期兼容；已有标签页的旧临时口令可升级为短期Cookie授权，之后移除旧临时口令。
- 设备之间仍共享每分钟2次、每天默认20次的用量；保留原有输错口令限制。设备授权不绑定IP。

### 每日一句可靠性

- 仅在模型成功返回可用句子后记为当天成功；失败不再永久阻断当天生成。
- 初次失败等待约1分钟，后续失败或限流等待约5分钟；自动失败最多3次，手动换句可在等待期结束后重试。重新解锁后允许恢复请求。
- 同一页面合并并发请求；支持Web Locks时协调标签页，其他环境使用短期本地租约兜底。服务端共享配额始终保留。
- 启动时先恢复授权；回到主页、恢复网络或应用时钟更新时重新判断。每天每个课表范围自动成功一次，手动换句另计。
- 新版缓存与旧版自动标记分开，避免旧的失败标记持续锁住生成。
- 本阶段的“每天自动”指网页打开／恢复后运行；关闭网页期间没有后台生成或系统推送。

### 主题轮换

- 事项和活动使用稳定来源编号，不再因列表排序变化而变成另一个话题。
- 保存近期句子及来源历史；最近两次提过的事项暂不再次送入每日一句，原事项与提前提醒保持原样。
- 普通无日期便笺不常驻每日一句摘要；有关联课程且当天或次日有该课时可纳入参考。
- 提示词让AI综合背景自主选一个角度，明确不固定追加事项、公式或提醒；普通闲聊允许没有个人事实引用。
- 本地兜底的“换一句”也可以换主题，避免被最高优先级事项的两种措辞锁定。

## 使用方式

正式网站 → 更多 → API与服务连接 → 输入原6位口令 → 勾选“记住这个设备（30天）” → 保存设置并解锁。

同一浏览器、同一正式网站内生效。本地预览、QQ内置浏览器和其他浏览器分别授权；记住设备不等于个人资料跨设备同步。

## 验证

- 自动化测试涵盖随机凭据、Cookie属性、8小时／30天到期、撤销、口令轮换、同源检查、PIN限流、D1故障关闭和共享用量。
- 前端模拟验证恢复并发去重、Cookie未被保留时不误报成功、口令不落本地存储、退出、失败后重试、成功后不重复自动调用、重新授权恢复、主题历史和标签页协调。
- 既有通知提取、天气、衣橱、小节、事项和日程测试继续运行。模型测试使用固定响应，不代表真实千问输出的准确率或多样性保证。
- 当前浏览器自动化权限受限，手机实际重开浏览器后的Cookie保持与表单布局尚未实机验收。不能把单元测试描述为实机通过。
