# 关联式常驻提示：第三批实施记录

日期：2026-10-23，北京时间。沿用已确认的紧凑首页方案；发布前基线为 `7671b86`。

## 已实现

- 在“记一下”中勾选“长期记着”。已有事项也能修改，不要求重新录入原话。
- 选择关联课程、出门准备、教学楼关键词、每天的时间段，或主动选择首页轻提示；也可以先只保存。
- 默认课前20分钟开始出现，可设0—180分钟。课内两小节之间的课间仍显示，整次课结束后退出当前主卡。课程详情可提前查看；明日准备按明天的课程匹配并去重。
- 提示默认为一行，长文字展开后完整查看。后续课程只加弱化的“常记”数量，展开才看到内容。
- 支持今天收起、今天恢复、暂停／启用、修改关联、改为普通事项、归档，以及移入回收站／恢复。今天收起按实际当天计算，次日恢复；暂停不会自动恢复或标为完成。
- “个人事项”增加“长期记着”分页，包含暂停与今天收起的记录，方便重新找到。
- 常驻提示不占首页默认一条事项的位置，不作为截止事项进入日历／提前催办，也不送入每日一句的事项上下文。

## 时间与关联的含义

| 设置 | 出现条件 |
| --- | --- |
| 关联课程 | 课程名称匹配；当前主卡遵守课前提前量，课程详情和对应日期准备中可查看 |
| 出门准备 | 必须指定课程或教学楼关键词；跟随匹配的课，提前放进准备内容 |
| 关联教学楼 | 课表地点包含所填关键词；若同时选择课程，两者都需匹配 |
| 每天的时间段 | 在设置的开始至结束之间出现；如关联课程，只在有该课的当天出现 |
| 首页轻提示 | 主动选择后在首页一行展示，仍可限制星期／日期 |
| 仅在事项中保存 | 保留原话，不猜测展示场景 |

所有区间采用含开始、不含结束。时间段可跨午夜：周五23:00—01:00延续至周六01:00之前，星期及限定日期按周五计算。星期不选表示每天适用；额外日期表示只在该日期生效，不是截止日期。

缺少关联课程、教学楼或完整时段时允许保存，管理页说明当前关联尚未完整设置；不会扩展成所有课程。教学楼使用课表中的文字匹配，不使用定位或推测人在何处。切换场景会忽略不用的字段，隐藏输入不会继续阻止保存。

## 数据与兼容

- 仍保存在当前浏览器，按学期／班级隔离；本地与正式站、不同设备各自保存。
- 个人事项备份升级为版本2，保存关联规则、暂停及今天收起状态；兼容原版本1并支持按编号合并恢复。
- 写入失败时保留原记录，表单保留输入。损坏／不支持的数据不会被自动清空。
- 写入新格式后，旧网页标签页不能用旧格式重写新字段；使用时刷新旧标签页即可。
- 沿用原有AI授权与配额，关联提示本身不调用付费API，也没有改动服务端密钥。

## 验收

- 新增模型与存储测试：课程匹配、教学楼条件、提前边界、课内课间、结束边界、未知时间、星期／指定日期、跨午夜、无关联、不完整时段、跨班级隔离。
- 状态测试：今天收起与次日恢复、暂停／启用、编辑保留、归档／恢复、回收站、取消常驻、备份版本1／2合并、写入失败保留原内容。
- 集成测试：普通截止提醒继续生成，常驻提示从每日一句与截止提醒中排除；文本转义、后续课程弱提示数量。
- 浏览器实际操作：从表单创建关联提示，当前课显示，课程详情查看，今天收起后从“长期记着”恢复，暂停／启用，保存不完整时段，完整时段切换，隐藏旧提前量不阻止保存，普通事项继续保存。
- 使用隔离的本机测试数据，分别模拟周五08:20和周四晚间，确认明日准备按翌日课程匹配。未修改真实用户事项。
- 320／390／812／1366px检查无横向溢出；提示摘要点击高度44px，首页普通事项仍默认一条；空提示容器不额外占据布局空档。最终验收页无控制台错误。
- 全部19个测试文件通过，前端JS语法和模块版本一致性检查通过。测试使用固定数据，不消耗真实千问调用，也不代表AI准确率测评。
